## Class 27 — Sprint 2
Short teaching block (30 min) before the work session:
1. `flutter analyze` and the `flutter_lints` rules in `analysis_options.yaml`.
2. `flutter test --coverage`.
3. Release build: `flutter build apk --release` / `appbundle`; app name and icon; `INTERNET` permission in the main manifest.
4. Performance check in DevTools: rebuild counts (use `const` widgets, `select`) and image memory.

Then a work session plus a dry-run demo with a partner, who scores it with the rubric.

## Class 28 — Demo day
- 7 minutes of demo + 3 minutes of Q&A per student or team.
- Required to show: offline mode (airplane mode), a background task result, the test run, and one piece of code the student is proud of.
- Grading: [final-project.md rubric](../final-project.md#demo-rubric-100-pts).
