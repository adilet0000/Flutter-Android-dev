# Kotlin / Jetpack → Flutter Map

Use this as the cheat sheet students keep open all semester.

## Language (Kotlin → Dart)

| Kotlin | Dart | Notes |
|---|---|---|
| `val` / `var` | `final` / `var` (and `const` for compile-time constants) | `const` widgets are an important Flutter performance habit |
| `String?`, `?.`, `?:`, `!!` | `String?`, `?.`, `??`, `!` | Sound null safety in both |
| `lateinit var` | `late` | |
| `data class` | class with `==`/`hashCode`/`copyWith`, usually generated by **`freezed`**; or a **record** `(String, int)` for small tuples | |
| `sealed class` + `when` | `sealed class` + `switch` expression with patterns | Exhaustive checking in both |
| `enum class` with properties | enhanced `enum` with fields and methods | |
| `object` (singleton) | `static final instance` or a `factory` constructor returning a cached instance | |
| `companion object` | `static` members | |
| Extension functions | `extension on Type { ... }` | |
| Generics `<T>`, `out`/`in` | Generics `<T>`, `T extends Bound` | Dart generics are covariant by default |
| Lambdas / higher-order functions | Closures, `void Function(int)` types, tear-offs (`print`) | |
| `listOf`, `mutableListOf`, `mapOf` | `[]`, `{}` literals; `List.unmodifiable` | |
| `map`, `filter`, `reduce`, `fold`, `groupBy` | `map`, `where`, `reduce`, `fold`, `groupBy` (from `package:collection`) | Dart's `map` returns a lazy `Iterable`, so call `.toList()` |
| Coroutines `suspend fun` | `Future<T> f() async` | |
| `launch` / `async` / `await` | Calling a `Future` (fire and forget) / `await` / `Future.wait` | |
| `Flow` / `StateFlow` | `Stream` / Riverpod state (or `ValueNotifier`) | |
| `Dispatchers.IO` / `Default` | Mostly not needed (I/O is async); use `Isolate.run` for CPU-heavy work | Dart is single-threaded per isolate |
| Structured concurrency, `viewModelScope` | Provider lifetime: `ref.onDispose`, `autoDispose` | |

## Local storage — which one when?

| Situation | Use |
|---|---|
| Relational data, queries, joins, reactive lists (a Room replacement) | **drift** — main teaching choice for Weeks 11–12 |
| You want to see and write plain SQL by hand | **sqflite** — shown once in Week 11 for comparison |
| Simple key-value pairs or small object caches (likes, drafts, settings) | **Hive CE** (`hive_ce`, the maintained community fork of Hive) |
| A handful of primitive settings (dark mode, onboarding flag) | **shared_preferences** |
